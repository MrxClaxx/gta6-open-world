Solmar Bay is a complete open-world crime game for the browser: explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police, and run five story missions.

## Run it

```sh
python3 -m http.server 8000 --directory game
# then open http://localhost:8000/index.html
```
